\# 🔢 Калькулятор энтропии



Приложение с графическим интерфейсом для вычисления энтропии.



\## 🚀 Функционал

\- Загрузка данных (изображения `sample.png`, текста `theory.txt`, таблиц `theory.xlsx`).

\- Вычисление энтропии по заданному алгоритму.

\- Визуализация результатов.

\- Сборка в `.exe` (скрипт `build\_exe.bat`).



\## 🛠️ Технологии

\- Python 3

\- Tkinter (GUI)

\- NumPy / Math (вычисления)

\- PIL / OpenPyXL (работа с файлами)



\## 📦 Как запустить

1\. Установите Python 3.

2\. Запустите: `python entro.py`
